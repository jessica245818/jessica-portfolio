How it works

The backend, in plain words

A backend is code that runs on a server instead of inside the visitor’s browser. It can receive requests, apply private logic, store data, or talk to other services. This demo deliberately does not need one: the rule is small and public, so the browser can calculate the answer immediately.

1 · Input The visitor enters three numbers.
2 · Browser JavaScript validates the values.
3 · Rule The documented baseline calculates a score.
4 · Output The page shows a review action and reason.

Nothing is sent to me, saved in a database, or transmitted to a third party. The data exists only in the open page until it is refreshed. If I later built a contact form, its backend would receive the form submission and deliver or store it; that is unnecessary for this feature.

Built as a static HTML page on GitHub Pages. Dynamic feature: client-side JavaScript only.
